# differential_calculus

Notes et fiches méthode de calcul différentiel.

## Documentation

La documentation est dans [`docs/`](docs/index.md) et s'affiche directement sur GitHub :

- [Fiche méthode](docs/fiche-methode.md) : calculer $\mathrm{d}f(a)\cdot h$ et prouver que c'est bien la différentielle
- [Normes usuelles](docs/normes-usuelles.md) : normes sur $\mathbb{R}^n$, les matrices, les espaces de fonctions et les applications linéaires

Elle peut aussi être construite en site web avec MkDocs (`pip install -r docs/requirements.txt`,
puis `mkdocs serve`).

La fiche existe en PDF imprimable : [`docs/Fiche-methode-differentielle.pdf`](docs/Fiche-methode-differentielle.pdf)
(source LaTeX : [`docs/fiche-methode.tex`](docs/fiche-methode.tex)).
